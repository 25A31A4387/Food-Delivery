# Food Delivery System in C++

## Project Overview
This is a console-based Food Delivery System developed using C++.

The project demonstrates:
- Queue Data Structure
- Graphs and Shortest Path Logic
- Object-Oriented Programming
- Menu Driven Application

Orders are stored using Queue, and delivery distance is calculated using a shortest path algorithm.

---

# Features

- Display Restaurants
- Place Food Orders
- Process Orders
- Display Pending Orders
- Delivery Distance Calculation
- Queue-Based Order Management
